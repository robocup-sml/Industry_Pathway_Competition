# SML Junior League

This Repository will hold the rulebook for the Junior League of RoboCup Industrial - Smart Manufacturing, which is expected to form during 2026.
Official documents will be added in due time.


## First event impressions

With the first event of the Major SML and [Embodied Autonomous Intelligence Workshop](https://github.com/robocup-at-work/sml-embodied-autonomous-intelligence/tree/main) taking place during the german open 2026 in cologne,
first challenges and collaboration formats have been identified.
This included remote-controlled operation of custom-built robotic platforms, e.g. by carrying euroboxes and navigating between other robots and drop-off-stations.
The official collaboration challenge between the major and junior SML formats has been featured in the [Live Stream](https://www.youtube.com/live/LqsHzzSVwH0?si=-iHAKcdHDy6YTJZ_&t=19500).
